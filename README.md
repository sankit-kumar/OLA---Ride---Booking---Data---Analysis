🚕 Ola Ride Analysis — SQL & Power BI

A data analytics project focused on analyzing Ola ride booking data using SQL and Microsoft Power BI to uncover business insights related to rides, revenue, cancellations, vehicle performance, and customer ratings.

📌 Project Overview

The objective of this project is to transform Ola ride booking data into meaningful business insights.
SQL was used for data analysis and business queries, while Power BI was used to create interactive dashboards and visualize key performance indicators.

Key Areas Covered

Ride volume and booking trends
Booking status analysis
Vehicle type performance
Revenue and payment methods
Customer and driver cancellations
Top customers by booking value
Customer and driver ratings

🛠️ Tools & Technologies
SQL — Data analysis and business queries
Power BI — Dashboard and data visualization
Power Query — Data cleaning and transformation
DAX — Measures and calculated metrics
Excel / CSV — Data source

📊 Power BI Dashboard
The Power BI dashboard is organized into five analytical sections.

1. Overall Analysis
Ride Volume Over Time
Analyzes the number of rides across different dates to identify demand patterns and trends.

Booking Status Breakdown
Shows the distribution of successful, customer-cancelled, and driver-cancelled bookings.

2. Vehicle Type Analysis
Top 5 Vehicle Types by Ride Distance
Identifies the vehicle categories contributing the highest total ride distance.

Average Customer Ratings by Vehicle Type
Compares customer satisfaction across different vehicle categories.

3. Revenue Analysis
Revenue by Payment Method
Analyzes revenue generated through different payment methods such as Cash, UPI, and Credit Card.

Top 5 Customers by Booking Value
Identifies high-value customers based on their total booking value.

Ride Distance Distribution Per Day
Analyzes daily ride-distance patterns and variations.

4. Cancellation Analysis
Customer Cancellation Reasons
Identifies the major reasons customers cancel rides.

Driver Cancellation Reasons
Analyzes the main reasons for driver-side cancellations.

5. Ratings Analysis
Driver Ratings Distribution
Analyzes the distribution of ratings received by drivers.

Customer Ratings
Evaluates overall customer satisfaction.

Customer vs Driver Ratings
Compares customer and driver ratings to understand their relationship.
